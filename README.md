# Race Posts

Turns an athlete photo and a race result into a 1080px Instagram post (4:5 post, square, or 9:16 story).

- Three layouts (overlay, print, split), six fonts, accent colours, team logo, per-element sizing
- Old → new time with the improvement, optional pace, placing and quote
- Race details, style, logo and handle are remembered on the device; "Next athlete" clears only the athlete fields
- Phone: **Save or share** opens the share sheet (Save Image, Instagram). Desktop: downloads the JPG
- Installable to the home screen and works offline after the first visit

Single static page — no build step. Hosted with GitHub Pages from `main`.
